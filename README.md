Sistema SAS para Foguete com ESP32

Este projeto implementa um Sistema de Estabilização Assistida (SAS) utilizando o microcontrolador ESP32.
O objetivo do sistema é monitorar a orientação e altitude do foguete em tempo real, ativando automaticamente um servomotor responsável pela correção da trajetória durante o voo.
Além disso, o sistema registra continuamente os dados de telemetria em uma memória Flash SPI para posterior análise do voo.
